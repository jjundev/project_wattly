# Calibration Mode

## 상태

- 단계: 기능 정의 초안
- 구현 난이도: 매우 어려움
- 권장 우선순위: 11

## 목표

배터리 셀을 회복시키는 기능이 아니라 BMS의 잔량·최대용량 추정 오차를 보정하는 장시간 충방전 절차를 자동화한다.

## 의존성

Calibration Mode는 다음 기능이 먼저 안정화되어야 한다.

- Top Up과 임시 충전 한도
- 수동·자동 방전
- 앱 종료·sleep·helper 재시작 상태 복원
- Heat Protection과 정책 우선순위
- 장시간 작업 진행 상태 저장

## 최소 기능 범위

초기 절차 후보:

1. 현재 상태와 예상 소요시간 안내
2. 100%까지 충전
3. 안정화 대기
4. 안전한 하한까지 능동 방전
5. 다시 100%까지 충전
6. 안정화 대기
7. 원래 충전 한도 복원

각 단계는 중단·재개 가능해야 하며 사용자가 언제든 안전하게 취소할 수 있어야 한다.

## 안전·동작 규칙

- 배터리 수명을 회복시키는 기능으로 표현하지 않는다.
- 정상적인 배터리에 빈번한 실행을 권장하지 않는다.
- Heat Protection을 자동으로 비활성화하지 않는다.
- 저잔량 구간에서는 sleep, 종료, 전원 분리 위험을 명확히 안내한다.
- 상태 전이는 앱 메모리가 아니라 지속 저장된 작업 상태를 기준으로 복원한다.
- 취소·오류 시 충전 허용 상태와 원래 한도를 복구한다.

## 권장 노출 조건

- 잔량 급락
- 비정상 종료
- 표시 용량의 큰 변동
- 장기간 중간 잔량에 고정된 뒤 사용자가 직접 요청한 경우

기본 주기 자동 실행은 제공하지 않거나 명시적 고급 옵션으로 둔다.

## 미결정 사항

- 안전한 방전 하한을 정해야 한다.
- 각 단계의 대기시간과 재시도 정책을 정해야 한다.
- 진단 증상이 없을 때도 실행을 허용할지 결정해야 한다.
- macOS가 자체적으로 수행하는 100% 보정 충전과 충돌하지 않는지 확인해야 한다.

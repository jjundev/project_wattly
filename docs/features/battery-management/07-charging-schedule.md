# 예약 충전

## 상태

- 단계: 기능 정의 초안
- 구현 난이도: 보통~어려움
- 권장 우선순위: 7

## 목표

사용자가 정한 시간과 반복 규칙에 따라 충전 한도 변경, Top Up, 충전 일시정지 등의 배터리 관리 작업을 자동 실행한다.

## 현재 Wattly 기반

- 충전 한도와 활성화 상태가 `AppStorage`에 저장된다.
- 앱은 helper에 충전 설정을 적용하고 상태를 조회할 수 있다.
- 아직 예약 작업 모델, 실행기, 실행 이력이 없다.

## 최소 기능 범위

지원 작업:

1. 충전 한도 설정
2. Top Up 시작
3. 충전 일시정지

지원 반복:

- 한 번
- 매일
- 평일
- 매주

추후 능동 방전과 Calibration이 안정화되면 예약 작업으로 추가한다.

## 안전·동작 규칙

- Mac이 꺼져 있거나 잠든 동안 정확한 시간 실행을 보장하지 않는다.
- 누락된 작업은 사용자가 `다음 기회에 실행`을 선택한 경우에만 wake 후 실행한다.
- 오래 누적된 작업을 한꺼번에 실행하지 않는다.
- 동일 시각에 충돌하는 작업의 우선순위를 명시한다.
- 실행 결과와 실패 이유를 이력에 남긴다.

## 미결정 사항

- 앱 내부 스케줄러와 Apple Shortcuts 중 어느 쪽을 기본 자동화 수단으로 할지 결정해야 한다.
- sleep 중 wake 요청을 시도할지 결정해야 한다.
- 월간·격주 반복과 시간대 변경 처리가 MVP에 필요한지 결정해야 한다.
